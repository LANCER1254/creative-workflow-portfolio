# 制作の見通しをつくる・3つのデモ

既存の絵コンテViewer・背景進行表・Writing Status Viewを、架空の短編で試せる静的デモへ切り出した公開準備版。描画機能や未測定の時短効果をうたうものではありません。

## 起動
このディレクトリで `python3 -m http.server 18128 --bind 127.0.0.1` を実行し http://127.0.0.1:18128/ を開く。依存JS/CSSはすべて同梱、外部CDN/サービス不要。ES modulesを使うためfile直開きは非対応です。

絵コンテ：指示編集→コマ順→JSON保存/読込・HTML出力。自動保存ではありません。
背景：状態編集→ブラウザに保存→JSON書出し/読込。ブラウザ保存は端末/ブラウザごと。JSONを別環境へ持ち出してください。
執筆：件数/工程絞り込み/関連資料の閲覧。元の機能どおり閲覧専用で、工程編集やGitHub連携はありません。JSONは合成表示入力の書出し/復元です。

## 設計と再利用
絵コンテ/背景のモデル・編集・HTML出力を同じ基盤から切出し、データ境界/画像検証/ブラウザ内保存を限定変更。執筆は既存集計/正規化/表示を再利用。コマ・背景・章・幾何学PNGはすべてこのデモ用の合成データです。原稿/実キャラ/実API/資格情報/実データは含みません。出力HTMLは文字列をエスケープし、JSONの画像は埋込PNG/JPEG/WebPに制限します。

本人とAIの役割：本人が課題・仕様・採否を判断し、AIが既存コード調査/限定実装/試験/文書整理を支援。実績・効果を未計測のまま数値化していません。

## 制約・公開判断
PC幅と390pxの自動操作を検証対象とし、実機スマホの本人受入とは区別。背景の保存はブラウザ容量に依存し、失敗時は保存済みと表示しません。別タブ更新を検出して拒否します。公開先/所有者/配布ライセンスは未決です。元コードにLICENSEが見つからなかったため、今回新しい利用許諾を勝手に付与していません。公開push/外部配備は行っていません。既存Git履歴とpublic_production外のファイルは配布対象ではありません。
