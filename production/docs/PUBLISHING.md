# 公開候補の境界

公開候補はこのpublic_productionディレクトリ内だけです。親cloneの既存ファイル・.git・履歴、内部証跡、元カード内容は対象外。今回の保存はローカル準備で、外部公開pushや可視性変更をしていません。

PUBLISH_MANIFEST.jsonに、この文書を含む公開候補の相対path・bytes・SHA-256を列挙します。manifest自身は自己参照を避け一覧対象外。候補ZIPはこのmanifestと列挙ファイルだけを格納し、ZIPからの読み戻しbytesを確認します。

配布先/所有者と配布ライセンスは未決です。原典にLICENSEが見つからなかったため新規許諾を付けていません。本人によるPC/実機スマホの表示受入、公開対象一覧、公開先、配布条件の確定を次担当の判断点として残します。

テストコードにあるexample.comのURLは外部画像の拒否を確認する入力です。実行時に要求されないことをブラウザ検証しています。アプリ内のgithub.com文字列は再利用したURL形式検査のホスト名で、架空サンプルに実GitHub参照はありません。
