# 保存と復元

1. このディレクトリ全体を保管し、静的HTTPでindex.htmlを開く。file直開きは使いません。
2. 絵コンテは「JSONを保存」で書出し、別環境の「JSONを読込」で復元。保存前のタブ終了に注意してください。
3. 背景は「ブラウザに保存」で同じブラウザへ保存。「背景JSONを書出し」で別環境へ退避し、背景モードの「JSONを読込」→「ブラウザに保存」で移行します。
4. 執筆は「合成データJSONを書出し」→「JSONで表示を復元」。元ファイルや実サービスを更新しません。

samples/の3つのJSONが初期サンプルです。絵コンテ/執筆には「合成例に戻す」があります。背景だけ初期化する場合はJSONバックアップを確保し、ブラウザ開発者ツールでpublic.production.background.r01とpublic.production.background.selected.r01だけ削除して再読込します。他のlocalStorageを全消去する必要はありません。

隔離版を停止する場合は、このデモ用に起動したHTTPサーバだけ停止してください。元ツールの復元やGit resetは不要です。公開準備版を配る場合はPUBLISHING.mdの限定ファイル集合を使い、親Git履歴を渡さないでください。
