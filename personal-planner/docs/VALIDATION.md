# 公開デモの検証記録

検証日：2026-11-01。対象はpersonal-plannerフォルダのブラウザ保存版です。

## 確認したこと

- Chromiumのデスクトップ画面で生活タスク6件の初期表示、進捗集計、編集、保存・読み戻しを確認。
- カレンダーへ移動し、変更後のタスク名・本人予定日が参照表示されることを確認。
- カレンダーに架空の予定を追加し、保存・読み戻し後に月表示と日別一覧へ表示されることを確認。
- Node.js組込みテスト3件PASS：合成データ初期化／保存／古い版の拒否／同じrunIdの再試行／危険URL拒否、予定の重複拒否／取消履歴／保存領域の分離、破損データの保持／デモ専用領域だけのリセット。
- HTTP環境でも起動できるよう、UUID生成にデモ専用フォールバックを用意。セキュリティトークンには使用しません。
- 公開対象の全ファイルを確認し、個人用サイトURL・認証設定・アカウント識別子・秘密鍵・DBファイル・個人タスクを収録しない構成を確認。
