# くらしと楽しみ — Personal Planner Demo

生活・趣味・購入予定を、かわいいパステルUIで整理する2画面のデモです。タスクの「次の行動」と、カレンダーの「いつ」を行き来できます。猫のイラストはSVGによる図形です。

## まず1分で試す

リポジトリ直下で `python3 -m http.server 8080 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8080/personal-planner/` を開きます。認証・APIキー・npm・ビルドは不要です。

1. 生活タスクのサンプルを編集し、状態や本人予定日を変えて保存。
2. 上部の「カレンダー」へ移動。タスクの予定日が参照表示されます。
3. 日付を選び「＋ 予定」で予定を追加。日別一覧から編集し、完了・取消へ変更。
4. JSONを書き出し、復元して保存内容を確認。「サンプルに戻す」はこのデモ専用の保存領域だけを初期化します。

## できること

- 生活／趣味／購入・セール待ちの3分類、未着手／進行中／保留／完了、検索・期限フィルタ。
- 本人予定日と相手・外部期限の分離、予算、資料URL、価格の確認日時・出典。
- カテゴリ別進捗、予定一覧、猫の装飾、PC／狭い画面向けレイアウト。
- 日本時間の月カレンダー・日別予定、終日／開始・終了時刻、制作・仕事カテゴリ。
- 生活タスクの予定日はカレンダーへ参照表示。タスクを二重作成しません。
- 同じ日・開始時刻・名前の予定の重複防止、保存revisionの照合、JSONバックアップ／復元。
- 取消は履歴を保持します。カンバンIDは参照用の文字列で、外部カードを変更しません。

## 公開デモとオンライン版の違い

| 項目 | この公開デモ | 本人用オンライン版の実装 |
| --- | --- | --- |
| データ | 架空サンプル | サインインした本人のデータ |
| 保存 | このブラウザのlocalStorage | ユーザーIDで分離したD1保存 |
| 認証 | 不要 | Sign in with ChatGPT |
| 会話から予定登録 | 含めない | 専用の認証付きツールを実装 |
| 外部アプリ・カンバン同期 | なし | 現時点では自動同期なし |

オンライン版の認証設定、サイト識別子、非公開URL、DB、個人タスク、資格情報、元Git履歴は収録していません。公開リポジトリには画面・純粋な入力検証モデル・デモ専用保存アダプターだけを追加しています。本人用Siteへの入口をこのデモへ埋め込んでいません。

## 保存の制約

ブラウザデータを消すとデモの入力は失われます。ブラウザや端末をまたいだ同期はありません。必要な内容はJSON保存してください。実個人データや秘密情報をデモに入力する必要はありません。

Web Locks対応ブラウザでは、デモの種類ごとに書込みを直列化します。非対応ブラウザでは保存直前の版照合だけとなり、別タブ間の原子的な同時更新保証はありません。本番サーバーのCASと同等とは扱いません。保存領域の制限・破損・容量不足は未保存として表示します。

## 本人とAIの役割

本人が課題、要件、優先順位、デザイン参照、採否を判断し、AIが既存UIの改修、保存処理、入力検証、試験、文書化を支援しました。全コードを本人が単独で手書きしたという実績表現ではありません。未測定の時短効果も主張しません。
