# Creative Workflow Portfolio

個人の創作活動で生じた「作業が散らばる・進捗が見えない・指示が伝わらない」を整理する、9つのブラウザ用ツールデモです。公開用の合成データで動作し、実際の制作資料や個人情報は含みません。

## 試す方法

GitHubの「Code → Download ZIP」で取得・展開し、このフォルダで次を実行します。Python 3を使用します。

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

ブラウザで http://127.0.0.1:8080/ を開くと、各デモへの入口が表示されます。終了はCtrl+Cです。通常利用にnpm、ログイン、APIキー、ビルドは不要です。GitHubのファイル閲覧画面ではHTMLアプリは実行されません。

## 技術・設計

HTML / CSS / Vanilla JavaScript。用途別の小さなモデルと画面に分離し、localStorage・JSONによる保存/復元を採用。保存競合や不正JSON、表示幅、出力時の文字列エスケープを検証しています。各フォルダの docs/VALIDATION.md に対象範囲・制約を掲載しています。画面例を収録したフォルダもあります。

## 本人とAIの役割

本人が制作上の課題、要件、優先順位、運用ルール、採否を判断し、AIが既存コードの調査、実装、試験、文書化を支援しています。全コードを本人が単独で手書きしたという実績表現ではありません。実務経験や未測定の時短効果を主張するものでもありません。

## 公開範囲と制約

2026-11-01公開。初回は公開準備済みの3フォルダを新しい履歴でまとめ、同日、生活タスクとカレンダーの展示版をpersonal-plannerへ追加しました。制作原稿、実キャラクター素材、実カード、非公開リポジトリ履歴、外部サービス認証は収録していません。各デモは独立した展示版で、本番バックエンド、AI自動実行、クラウド同期を含みません。ブラウザデータを削除すると保存内容が失われるため、必要に応じてJSONを書き出してください。
