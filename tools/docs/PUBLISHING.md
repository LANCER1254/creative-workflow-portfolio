# 公開予定範囲

この `public_tools/` 配下のみが候補です。ファイル一覧とSHA256は `public-files.json`（一覧自身のhashを除く）。ZIPも同じファイル集合だけを含みます。

- 入口HTMLとREADME
- memo/: 付箋デモ1HTML
- kanban/: カード/予約/融合/会議状態の既存モデル、HTML/CSS/ブラウザ内保存版JS、合成sample.json
- character/: 既存モデル/計算/画像読込/描画/入力/HTML/CSSと合成サンプル・条件JSONのdemo.js
- docs/: 設計由来、検証JSON・説明、合成画面8枚
- tests/: 意味のあるブラウザ操作検証、禁止参照の静的検査
- package.json: 任意の検証依存

公開前の残確認：公開先repo/所有者、配布ライセンスとソース権利の確認、本人による表示受入。原典2repoのルートにLICENSE/COPYINGは見つかりませんでした。オープンソース許諾を付与済みとは扱わず、この候補へ新しいライセンスを勝手に設定していません。
