# 制作の「散らばる・伝わらない」を減らす3ツール

思いつきを用途別に整理する **Memo Petal**、依頼から結果・次担当までつなぐ **付箋カンバン**、立ち絵の身長比を確認する **Character Size Viewer**。既存の制作ツールから切り出し、初見で用途が伝わる合成データの公開準備版にしました。

## 1分で試す

`index.html` をブラウザで開き、3つの体験から選びます。インストール・ログイン・外部APIは不要です。推奨はローカルHTTPでの起動です。

```sh
python3 -m http.server 18127 --bind 127.0.0.1 --directory .
```

ブラウザで `http://127.0.0.1:18127/` を開きます。ポート使用中なら別の空きポートを指定してください。終了はターミナルでCtrl+C。HTML直接起動も検証済みですが、ブラウザ設定によってファイルURLの保存領域が分かれます。HTTP版と同じ保存領域とはみなしません。

| ツール | 困り事 → 操作 → 結果 |
| --- | --- |
| Memo Petal | メモが散らばる → 黄色の付箋を書き換え「将来アイデア」へ移す → ボードから再発見する。チェックリストで残件も確認 |
| 付箋カンバン | 結果だけでは次に進めない → 黄色のカードに結果・残件・次担当を記録 → Doneと予約順を更新し、次の確認につなぐ |
| Character Size Viewer | 画像ごとに立ち絵サイズが違う → サンプルを開き身長・基準キャラを設定 → 足元を揃えた縮尺を比較 |

## 保存・復元

Memo Petalとカンバンは、このデモ専用のlocalStorageに保存します。JSON保存でダウンロードし、空の別ブラウザでJSON読込/復元すると持ち出せます。置換前には確認があり、不正JSONは保持中のデータへ適用しません。別タブで変更された古い内容の保存は拒否します。ブラウザデータを消すと失われるため、必要なメモはJSON保存してください。

Character Size Viewerはメモリ内で比較し、JSON保存はサンプル3体の身長・基準・表示倍率だけが対象です。追加したPNG自体はJSONに入りません。ページ再読後はPNGを再度選択します。再配置は読込順の自動整列で、ドラッグ並べ替えは未実装です。画像の上下に余白がある場合は、人物の実際の頭頂/足元を自動検出しません。

スマホ幅では付箋は縦に並び、カンバンは列ナビゲーション、比較表/プレビューは領域内スクロールで操作します。PCのドラッグ・リサイズをスマホ同等対応とは扱いません。実スマホ/タッチによる本人受入は未実施です。

## 設計と技術

HTML / CSS / Vanilla JavaScript。ビルドは不要です。既存モデル・入力/描画・予約ルールを再利用し、データと通信の境界を変えています。カンバンの本番API/CAS/クラウドを、このデモではWeb Locksと保存直前の版照合によるブラウザ内保存へ置き換えました。本番サーバーの同時更新保証と同じものではありません。

実メモ・実カード・非公開原稿・本編のキャラ素材は含みません。キャラ3体はSVG図形、メモ/カードは架空の展示準備です。AI起動・実タスク実行・クラウド同期・本番ENDは、このデモのボタンから実行されません。
