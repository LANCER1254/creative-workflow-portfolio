## 再現

通常の閲覧には依存パッケージは不要です。テストする場合：

```sh
npm install
npm run test:static
npm run test:browser
```

ブラウザテスト自身がOS割当ポートのローカルHTTPサーバーを起動し、合成データと一時ブラウザだけで確認します。公開画面とレポートを再生成し、最後に自身のサーバーを終了します。運用中のサービスや実データは使用しません。
